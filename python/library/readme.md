## pip
- python을 패키지 설치 프로그램
- 스타일패키지(라이브러리) 설치 관리 도구

## 크롤링 이란?
```
크롤링(crawling)은 웹페이지를 그대로 가져와서 거기서 데이터를 추출해 내는 행위

 * 크롤링(crawling)과 스크레이핑(scraping)은 실질적인 자아는 없지만, 일반적으로 스크립핑은 하나의 페이지를 수집하는 것이며, 크롤링은 동적으로 웹페이지를 돌아다니면서 수집하는 것을 말한다.
```

## selenium 이란?
```
웹 애플리케이션 테스트를 위한 포터블 프레임워크이다.
웹 상에서 정적인 페이지를 탐색하는데 사용하던 beautifulsoup같은 패키지가 하지 못하는 동적인 크롤링을 지원한다.

 * 동적인 크롤링 : url 상에는 아무런 변화없이 동작하는 웹페이지에 대한 크롤링을 지원한다.
```

## 크롤링
- 정적 크롤링 Beautiful Soup
- 동적 크롤링 selenium (페이지 이동하여 크롤링, 시간은 더 걸림)
    - pip install selenium
